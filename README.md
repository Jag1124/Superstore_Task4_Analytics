# Superstore Task 4 – Data Analytics & Business Intelligence
## Project Overview
This project focuses on analyzing Superstore sales data using Power BI to generate meaningful business insights and support data-driven decision-making.
## Objectives
- Build a Star Schema Data Model.
- Create DAX measures for business KPIs.
- Perform Month-over-Month (MoM) and Year-over-Year (YoY) analysis.
- Develop an interactive Executive Dashboard.
- Prepare an Executive Business Report.
## Tools & Technologies
- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Microsoft Excel
## Key Performance Indicators
- Total Sales
- Total Orders
- Total Customers
- Previous Month Sales
- MoM Growth %
- Previous Year Sales
- YoY Growth %
## Key Insights
- Total sales are approximately **$2.26 million**.
- **2018** recorded the highest annual sales.
- **Technology** was the top-performing category.
- **West** was the highest-performing region.
- Sales showed an overall upward trend from 2015 to 2018.
## Project Deliverables
1. Power BI Dashboard (`.pbix`)
2. Data Model Screenshot
3. DAX Measures List
4. Dashboard Screenshot
5. Executive Business Report (PDF)
## Dataset
Superstore Sales Dataset containing order, customer, category, region, and sales information.
